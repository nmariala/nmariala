## What I Build

### 📦 Demo Stok

A public, self-hosted inventory management demo built from a real-world operational problem and redesigned with generic data for portfolio use.

- [Live Demo](https://demo-stock-app.giehomelab.my.id)
- [Repository](https://github.com/nmariala/demo-stock-web)

The demo includes:

- Inventory by warehouse and condition
- Stock-in / stock-out transactions
- Transaction history
- Product management
- Packing and capacity calculators
- Custom authentication and server-side sessions
- Isolated **Try Demo** sandbox for each visitor
- PostgreSQL + REST API
- Self-hosted Linux deployment

The public demo is intentionally separated from any real operational/company data.

### 🖥️ Homelab

A small self-hosted infrastructure project built with limited hardware.

It includes a server management dashboard, service monitoring, storage/NAS features, Linux services, reverse proxying, HTTPS, and remote access.

- [Homelab Dashboard](https://github.com/nmariala/homelab-dashboard)

The point is not having expensive hardware. The point is learning how to make useful infrastructure work with what is available.

### 💍 Wedding Organizer

A private business-oriented web application built to manage Wedding Organizer operations.

The project covers workflows such as:

- Leads and pipeline
- Clients and projects
- Checklists and schedules
- Rundown
- Vendors and sourcing
- Notes
- Services
- Budget
- Project reports
- Client-facing views and share links

The repository is private, but the project is part of my portfolio work and demonstrates how I approach software around real business workflows.
