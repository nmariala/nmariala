## Featured Project: Stock SDI Demo

A self-hosted inventory management demo built while learning full-stack development and deployment.

It started as the kind of problem I knew from my logistics days — keeping track of stock — and became a complete application running on my own server:

```text
Frontend        Next.js / React + TypeScript + Tailwind CSS
→ REST API      Node.js / Express
→ Database      PostgreSQL
→ Auth          Custom authentication with server-side sessions
→ Server        Debian Linux, Nginx, systemd
→ Network       Cloudflare Tunnel, HTTPS, UFW firewall
```

It's a learning and portfolio project, not a product — and that's exactly what it's meant to be.
